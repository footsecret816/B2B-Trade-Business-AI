# Project Memory Schema

Recommended fields:
- project_id
- customer_id
- product/category
- stage
- confirmed_requirements
- confirmed_capabilities
- quotation_terms
- MOQ/payment/lead-time state
- decisions
- open_issues
- next_actions
- owners
- source
- recorded_at
- effective_at
- supersedes / superseded_by

Project facts outrank company-general facts for the active project.
