# EVAL-003 — Mature Project Follow-Up

## Test input
A mature project is near decision but the customer has not replied for several days. The user wants a warm follow-up without pressure.

## Required behaviors
- Do not infer rejection from silence.
- Use project history as the reason for re-engagement.
- Avoid generic chasing.
- Do not promise an unapproved concession.
- Reopen the decision naturally.
