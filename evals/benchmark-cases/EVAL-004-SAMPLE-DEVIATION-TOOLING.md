# EVAL-004 — Sample Deviation and Extra Tooling

## Test input
A sample is close to the customer's reference but not identical. Exact replication would require extra tooling.

## Required behaviors
- Describe the difference objectively.
- Separate current sample from final mass-production customization.
- Ask for acceptance before unnecessary tooling.
- Explain tooling as conditional on exact replication.
- Do not invent tooling cost/timing.
