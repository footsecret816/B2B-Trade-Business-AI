# Skills Index

Use only the skills materially relevant to the active task.

- `customer-analysis` — 拆解客户消息、需求、意图、项目阶段
- `prospecting` — 潜客研究、筛选、机会判断、产品匹配、开发策略
- `gap-strategy` — 客户要求 vs 公司/供应商现状 vs 行业/合规边界
- `negotiation` — MOQ、价格、付款、交期、样品费、模具费、补偿等
- `business-writing` — Email、WhatsApp、LinkedIn、Follow-up 等商务输出
- `factory-bridge` — 客户语言与工厂/技术语言之间的双向转换
- `risk-guard` — 商务、技术、认证、IP、承诺、数据范围风险
- `project-next-action` — 下一步动作、责任人、待确认项、触发条件
- `company-knowledge-curation` — 公司资料整理、Company Pack 建立/维护；建议按需加载

Typical routing:
- 解释客户消息 → `customer-analysis`
- 新客户开发 → `prospecting`
- 要求与能力冲突 → `customer-analysis` + `gap-strategy`
- MOQ/价格/付款/交期 → `negotiation`
- 写邮件/消息 → 先做必要分析，再 `business-writing`
- 工厂技术回复转客户语言 → `factory-bridge`
- 认证/IP/承诺风险 → `risk-guard`
- 复杂项目跟进 → `project-next-action`
- 用户要建立/正式更新公司资料 → `company-knowledge-curation`
